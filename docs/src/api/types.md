# Types

`submit`, `close`, and `roll` return an `Order`. The errors of the package are `AlpacaError` and `AlpacaSequenceError`. The legacy return types, such as `Account` and `Position`, are on the [Legacy API](legacy.md) page, and the streaming values `Bar`, `Quote`, and `Trade` are on the [Streaming](streaming.md) page.
