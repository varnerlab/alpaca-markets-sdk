Reading data

Reading has two steps. url builds the request URL from a read model, and api sends the request, follows next_page_token until the last page, and returns the result of the handler.

using Alpaca
using Dates

client = load_client()

model = MyStockBarsEndpointModel(symbols = ["AAPL", "MSFT"], timeframe = "1Day",
                                 start = Date(2025, 1, 1), finish = Date(2025, 6, 30))
url(client, model)           # the URL of the first page
bars = api(client, model)    # a DataFrame with every page

The default result

The default handler of every read model returns a DataFrame. An endpoint that returns one record, such as the account, the clock, one asset, one order, one position, or one contract, returns a DataFrame with one row.

A missing value is missing in a column. Timestamps are DateTime in UTC, and prices and sizes are Float64. The columns of a bars table are timestamp, symbol, open, high, low, close, volume, trade_count, and vwap. A snapshots table has one row for each contract, and the nested objects (the latest quote, the latest trade, and the greeks) are columns with a prefix.

MyAssetsEndpointModel has no tradable_only field, because tradable_only is not an Alpaca query parameter. To keep only the tradable assets, filter the tradable column of the DataFrame.

Custom handlers

The handler keyword of api replaces the default handler. A handler is a function of the model type and the response body as a String: handler(Type, body). A handler sees only the response, so any step that needs a value from the request happens after api returns.

url(base::String, model::MyAccountEndpointModel) -> String

Build the URL string for the Alpaca /account endpoint. An HTTP GET call to this URL returns the account of the client: cash, buying power, and status.

Arguments

  • base::String: the base URL of the API, e.g., "https://paper-api.alpaca.markets/v2".
  • model::MyAccountEndpointModel: the endpoint model that holds the fields of the request.

Returns

  • String: the complete URL string.

Throws

  • None: this method builds a string and does not call the network.

Alpaca.api — Function
api(client::AlpacaClient, model::AbstractAlpacaEndpointModel;
    handler::Function = _default_handler)

Make the HTTP call for an endpoint model and process the response body with a handler. A paginated endpoint is called once for each page, and the handler results are merged in page order.

Arguments

  • client::AlpacaClient: the client that holds the credentials and the base URLs.
  • model::AbstractAlpacaEndpointModel: the endpoint model that describes the request.
  • handler::Function: the function that receives the type of the model and the body of a page as a String.

Returns

  • The result of the handler. A paginated endpoint returns the merged result of all pages.

Throws

  • AlpacaError: when the response status is not in the range 200 to 299.
